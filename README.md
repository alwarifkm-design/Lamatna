# لمة العائلة — تحدي العائلة

لعبة عائلية تفاعلية للمجالس: شاشة عرض (بروجكتر) + جوالات المتسابقين + لوحة إدارة مخفية.

## التشغيل

```bash
# من المجلد الرئيسي
npm install
cd server && npm install && cd ..
cd client && npm install && cd ..

npm run dev
```

- **شاشة العرض (البروجكتر):** [http://localhost:5173](http://localhost:5173)
- **لوحة الإدارة:** زر الإعدادات ⚙ → رمز الإدارة `242011` → `/admin`
- **المتسابقون:** مسح الباركود أو [http://localhost:5173/play?room=XXXXXX](http://localhost:5173/play)

الخادم: `http://localhost:3001`

## سير اللعب

1. الأدمن: إنشاء لعبة جديدة → يظهر الباركود والرمز على الشاشة
2. إضافة أسئلة يدوياً أو «سؤال عشوائي» (يُفلتر حسب العمر)
3. بدء اللعبة → السؤال على الشاشة فقط
4. تحديد وقت الإجابة → «متابعة» → الخيارات على الجوالات + العداد
5. النتائج → «متابعة» للسؤال التالي
6. منصة التتويج عند الانتهاء

## النشر على الإنترنت

**Vercel** للموقع + **Supabase** للعبة (بدون Render).

راجع **[SUPABASE.md](./SUPABASE.md)** و **[DEPLOY.md](./DEPLOY.md)**

## الإنتاج المحلي

```bash
npm run build
cd server && set SERVE_STATIC=true&& npm start
```

ضع `CLIENT_ORIGIN` و `PORT` حسب بيئتك.
